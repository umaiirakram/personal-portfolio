### 📦 How to Run Locally

```bash
git clone https://github.com/umaiirakram/personal-portfolio.git
cd personal-portfolio
# Just open index.html in browser - No server needed!
```

### ⚠️ Important - File Name

> **File MUST be `index.html` (lowercase)!** GitHub Pages is case-sensitive. `Index.html` with capital I gives 404 error.
