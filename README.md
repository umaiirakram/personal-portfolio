### 🚀 How to Use This For Your New Repository

#### Option 1: Create New Repo on GitHub (Recommended)
```bash
# 1. Go to github.com/new
# 2. Repository name: personal-portfolio (or your choice)
# 3. Make it Public
# 4. Don't initialize with README (since you have this file)

# Then in your local folder:
git clone https://github.com/umaiirakram/personal-portfolio.git
cd personal-portfolio

# Copy the index.html file you downloaded from here
# Make sure file name is lowercase: index.html (not Index.html)

git add .
git commit -m "Initial portfolio commit - umaiirakram"
git push origin main

# Then enable GitHub Pages:
# Go to Settings -> Pages -> Source: main branch / root -> Save
# Your site will be live at: https://umaiirakram.github.io/personal-portfolio/
```

#### Option 2: Direct Upload
1. Create new repository on GitHub
2. Click **Upload files**
3. Upload `index.html` (make sure lowercase!)
4. Upload `README.md` (this file)
5. Commit
6. Go to **Settings -> Pages -> Enable**

### ⚠️ Important Notes
- **File name MUST be `index.html` (lowercase)** - GitHub Pages is case-sensitive! `Index.html` with capital I will give 404.
